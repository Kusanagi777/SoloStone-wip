8. THE FAIR-VIEW CLONE FIX (commit 1ddccb4), found by this regression
- First full bosspilot pass (before the fix): f04-player had 1 fallback (game fixp_04_433, DRUID_PRIEST Elise against
  the Voone-hero fixture, turn 20), stable in both runs. A scratch copy of the harness (verify/.out/tmp/dbgf04, not
  committed) printed the stack: KeyNotFoundException in AdaptiveCostEffect.CloneDetached <- TriggerManager.CloneHandlers
  <- Game clone <- FairBotState.Apply. The owner was the run player's TRL_313 Scorch (id 103, HAND), whose adaptive cost
  keeps an end-of-turn callback; the boss's fair view replaces and renumbers the run player's hidden hand
  (CanonicalizePrivateActors), so no entity was left under id 103 and every clone of that view threw.
- Fix: CloneDetached returns null for an owner the game does not hold, and CloneHandlers drops that callback (only the
  path that threw changes). Regression suite p8w4/c-w4fix Y1-Y4 (Y3 failed before the fix with the same exception).
- Proof that nothing else moved: after the fix every run log equals its pre-fix run log (timing lines aside) and every
  bosspilot result of the pre-fix pass equals the post-fix one except f04-player (4 lines: that game now 0 fallbacks,
  22 turns, and the summary line). Pre-fix results: verify/.out/runs-prefix, verify/.out/bp-prefix.
